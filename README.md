# Project SYNAPSE

## Quickstart

1. Install dependencies:
   ```bash
   pip install streamlit pandas
   ```

2. Generate Mock Data:
   ```bash
   python3 src/data_generator.py
   ```

3. Run Benchmark (Optional):
   ```bash
   python3 src/benchmark.py
   ```

4. Launch the App:
   ```bash
   streamlit run src/app.py
   ```
